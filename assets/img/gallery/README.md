# 현장 시공 갤러리 이미지 (교체용 21장)

메인 페이지 "현장 시공 갤러리" 섹션과 전 지역·서비스 페이지의 상단 이미지 영역에서
이 폴더의 `01.jpg` ~ `21.jpg` 를 사용합니다. 현재는 자리표시(브랜드 플레이스홀더)
이미지가 들어 있으며, **같은 이름으로 덮어쓰면 즉시 교체**됩니다.

## 업로드 위치
```
assets/img/gallery/01.jpg
assets/img/gallery/02.jpg
...
assets/img/gallery/21.jpg
```
- 이 폴더(`assets/img/gallery/`)에 **같은 파일명**으로 사진 21장을 올리면 끝입니다.
- 파일명·확장자(`.jpg`)를 그대로 유지하세요. 별도 빌드/코드 수정이 필요 없습니다.

## 권장 사양
- 비율 **16:9**, 최소 **1280×720px** (예: 1600×900), 용량은 장당 300KB 이하 권장.
- webp를 쓰고 싶다면 이미지를 올린 뒤 `pages.py`의 `gallery_pic()`/`home_gallery()`에서
  확장자만 `.webp`로 바꾸고 `python3 pages.py`로 재빌드하세요.

## 어디에 노출되나
- **메인 페이지**: `01`~`21` 전체가 "현장 시공 갤러리" 그리드로 노출됩니다.
- **지역/서비스 페이지**: 페이지(지역명) 기준으로 21장 중 1장이 결정적으로 선택되어
  상단 히어로 우측 이미지 영역에 표시됩니다(지역마다 다른 사진이 분산 노출).
