# 현장 시공 갤러리 이미지 (21장)

메인 페이지 "현장 시공 갤러리" 섹션과 전 지역·서비스 페이지 상단 이미지 영역에서
이 폴더의 `01.webp` ~ `21.webp` (실제 시공 사진, 16:9, 장당 약 50KB)를 사용합니다.

## 교체 방법
- 같은 파일명(`NN.webp`)으로 새 이미지를 덮어쓰면 즉시 교체됩니다. 코드 수정 불필요.
- 권장 사양: **16:9 비율, 1280×720px, webp, 장당 50KB 안팎**.
- jpg로 바꾸려면 이미지를 올린 뒤 `pages.py`의 `gallery_pic()`/`home_gallery()`에서
  확장자만 `.jpg`로 바꾸고 `python3 pages.py`로 재빌드하세요.

## 노출 위치
- **메인 페이지**: `01`~`21` 전체가 "현장 시공 갤러리" 그리드로 노출.
- **지역/서비스 페이지**: 페이지(지역명) 기준으로 21장 중 1장이 결정적으로 선택되어
  상단 히어로 우측 이미지 영역에 표시(지역마다 다른 사진이 분산 노출).
